# Pocket Budget | الميزانية الشخصية

تطبيق ويب لإدارة الدخل والمصروفات والميزانيات والحسابات وأهداف الادخار. يعمل على GitHub Pages دون خادم خلفي.

## المزايا
- واجهة عربية RTL مع خيار الإنجليزية.
- تسجيل الدخل والمصروفات والتحويلات الداخلية بين حسابات العملة نفسها.
- دعم عملات متعددة لكل شخص ولكل حساب (مثل QAR وEGP وUSD وEUR وغيرها). تغيير عملة حساب له معاملات مسجلة محظور لحماية السجلات التاريخية؛ أنشئ حسابًا جديدًا بالعملة الجديدة.
- حساب أرصدة منفصلة لكل عملة؛ لا يجمع التطبيق عملات مختلفة ولا يخترع أسعار صرف.
- ميزانيات شهرية حسب التصنيف، وأهداف ادخار، وتقارير.
- بحث وتصفية، وتصدير CSV، ونسخ احتياطي/استعادة JSON.
- تخزين محلي Offline-first ودعم أساسي للعمل دون اتصال عبر Service Worker.

## النشر
الموقع ثابت؛ ضع الملفات في جذر الفرع الذي تم ضبط GitHub Pages للنشر منه:
- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`

لا يحتاج إلى Node أو pnpm أو مفاتيح API أو أسرار GitHub.

## البيانات والخصوصية
البيانات تبقى في Local Storage بالمتصفح وعلى الجهاز الحالي. حذف بيانات المتصفح أو تغيير الجهاز قد يؤدي إلى فقدها؛ نزّل نسخة JSON دورياً واحفظها في مكان آمن. لا تخزن كلمات مرور أو بيانات بطاقات أو معلومات مصرفية سرية. لا توجد مزامنة سحابية في هذه النسخة.

## ملاحظات محاسبية
- لا يتم جمع أرصدة بعملات مختلفة في إجمالي واحد.
- التحويل بين حسابين يسجل كحركة داخلية لا كدخل أو مصروف.
- الميزانية تقارن المصروفات الفعلية في الشهر بالحد المحدد.
- التطبيق أداة تنظيم شخصية وليس نظاماً مصرفياً أو بديلاً عن كشوف الحسابات.

## استعادة النسخة السابقة
عند أول تشغيل، يحاول التطبيق ترحيل بيانات الإصدار السابق `pocketBudget.v1` إلى بنية الإصدار الحالي. احتفظ بنسخة من بيانات المتصفح القديمة حتى تتأكد من ظهور كل سجلاتك.
